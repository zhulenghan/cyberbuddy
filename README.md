# Cyber Buddy - AI-Powered Desktop Pet Chrome Extension

> An intelligent companion that adapts to your browsing behavior and helps you stay focused.

## 🏗️ Monorepo Structure

```
cyberbuddy/
├── extension/          # Chrome Extension (WXT)
├── backend/            # AWS Services
├── shared/             # Shared code
└── docs/              # Documentation
```

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start extension development
npm run dev:extension
```

See full documentation in [README.md](./README.md) and [docs/architecture.md](./docs/architecture.md)
