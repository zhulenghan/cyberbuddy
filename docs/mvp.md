## **3\. 核心需求**

### **3.1  核心功能需求描述[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0)**

| 需求 ID | 功能模块 | 优先级 | 描述与设计目标 | 需求实现方式 | 核心卖点/差异化 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **P-1** | **特别的宠物形象生成** | **P0 (必须)** | 用户可输入特别的文字描述（如“一只戴着宇航员头盔的牛油果”），生成独特的像素化2D 宠物形象。 | 将用户输入的文本和宠物形象生成的prompt结合，调用banana api生成白底图像，通过代码转为透明底图像。下载每一次生成的图像并储存[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0) 注意：用户通过交互可以查看储存在generation history中的图像。 | **形象的“无限性”**，解决市面形象同质化问题。 |
| **P-2** | **根据用户行为实时跟随的宠物形象** | **P0 (必须)** | 宠物能实时跟随用户当前**激活**的**任何浏览器窗口**，并呈现符合用户行为的**宠物形象**（如用户从学习网站切换到视频网站，宠物要立刻跟随，给出不同的反应）。  | 预先设置5种网页行为，当用户点击生成宠物时后台根据prompt生成对应的5种图像[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0)和gif所需的图像，储存下来等待调用。 调用：等用户开始使用并切换浏览页，后台抓取到浏览页的部分文本信息，通过匹配得到最符合的label，再把对应的静态图像资产呈现出来（用户悬停在静态宠物图像超过2s时，换成动态gif） | **“无感陪伴”的核心体现**。 |
| **P-3** | **活跃浏览页的浏览时间计时** | **P0 (必须)** | 监听用户每个浏览页的活跃时长并计时 | ![][image1] 计时实现请问AI。 专注报告：抓取每个浏览页的部分文本信息并将其匹配到符合的label，用户要查看专注报告时，把所有统计的计时增加到各个label。 轻量级交互对话：用户询问我专注了多久时可以告诉用户截至现在你已专注了多久[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0) | 专注报告，轻量级交互对话时需要用到 |
| **P-4** | **每日专注报告** | **P0 (必须)** | 在报告页面中，呈现：每日行为占比、宠物个性化暖心话术等板块 | 用户点击生成今天的报告的按钮后，调用API通过[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0)来生成宠物个性化暖心话术，并对浏览时间计时进行数据可视化呈现 | 给用户带来成就感，陪伴感。满足打工人/学生党的**情绪价值**和**效率需求。** |
| **P-5** | **无痛点自动出现** | P1 (重要) | **确保每次打开新网页、新标签页或新窗口**时，宠物**无需用户手动点击**即可立即加载和显示。 | 扩展程序应设置**默认“在所有网站上”自动运行** | **解决用户痛点**，优化使用体验。 |
| **P \- 6** | **登录系统** | **P0 (必须)** | **Sign in with Google account** | 要在 Chrome 扩展程序中实现 **“使用 Google 账号登录”** 的功能，你需要使用 Chrome 扩展程序 API 中的 **`chrome.identity`** 模块。这是 Google 官方推荐和支持的，用于安全地获取 Google 用户身份、OAuth 2.0 令牌（Token）并代表用户访问 Google API | **简化登录，让用户更快使用上我们的产品** |

### **3.2 轻量级交互**

| 需求 ID | 功能模块 | 优先级 | 描述与设计目标 | 需求实现方式 | 结合赛博搭子定位 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **F-1** | **专注计时器（Clock）** | **P0 (必须)** | 用户点击宠物菜单栏中的计时器功能，可以进行某些任务的计时**。宠物会有对话框提示和小的timer悬浮。 若用户切换到其他类别（娱乐、社交），宠物会弹出**轻量级对话框提醒/提示。 | 计时器可视化 用户使用专注计时器模式时激活对话框功能（无须api，直接展示预先设置的提醒话术） | **强化“赛博搭子”身份**，帮助打工人/学生党提高效率。 |
| **F-2** | **AI短期记忆与个性化对话体验）** | **P0 (必须)** | 能记住用户设定的宠物的“人设”和当天对话的上下文记忆互动（暂时不考虑长期记忆）。互动应是**轻量级**的（例如：用户输入一个指令/情绪，宠物给出简短的反馈）。 | 短期上下文记忆 Prompt API调用[PROMPT](https://docs.google.com/document/d/1X8_qO0MMh343IlOvaJVWzhYrfHFn6A3Mn7vTYasx6Tc/edit?tab=t.0) | 不设置复杂的养成系统。减轻用户负担，符合**“不花精力”**的定位。 |

### **3.3 运营与设置**

| 需求 ID | 功能模块 | 优先级 | 描述与设计目标 | 需求实现方式 | 结合赛博搭子定位 |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **C-1** | **分享/推荐拓展程序** | P1 (重要) | 用户通过复制链接（含有spaceid），或者保存卡片图像（含有自己当前使用的**AI** 宠物形象和链接）分享到社区。 | 生成链接如：https://cyperbuddy.com/link/?id=1A40F01EF9CA通过代码生成图片型分享卡片 | 不设置社区（我们不打算有社交属性，更focus你的**”独家“**宠物）。 |
| **C-2** | **成就系统** | P1 (重要) | 基于专注时长、陪伴天数等设立轻量级成就（如“专注达人”、“陪伴一百天”），奖励**新的宠物生成次数**。 | 后端一个新的表，记录专注计时、使用天数、剩余宠物生成次数等 | 提升长期粘性，但避免复杂的养成任务。 |
| **C-3** | **语言** | P2 (一般) | 默认中英双语，更多语言考虑使用translate API | Translate API | 支持更多地区玩家 |
| **C-4** | **付费系统** | P3 (不急) | 付费用户可享用无限宠物生成次数（定价不详） | 后端一个新的表，记录专注计时、使用天数、剩余宠物生成次数等 | 无 |
| **C-5** | **隐私保护** | P3 (不急) | 用户可以一键删除所有数据 | 后端删除 | 给用户安全感、掌控感 |
