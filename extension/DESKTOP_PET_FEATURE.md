# 桌宠功能说明

## 功能概述

现在，当用户点击 Home 页面或 Instruction 页面的 "Meet with your buddy" 按钮后，桌宠会出现在当前浏览的网页上！

## 已实现的功能

### 1. 🐾 桌宠显示
- 点击按钮后，桌宠会悬浮在当前网页上
- 桌宠支持 **GIF 格式动画**
- 桌宠**可拖动**，可以移动到屏幕任意位置
- 位置会自动保存，刷新页面后保持在同一位置

### 2. 🎮 互动菜单
点击桌宠会弹出功能菜单，包含：

#### ⏰ 专注计时器
- 浮动的计时器窗口
- 支持 15、25、45 分钟快速设置
- 可以启动、暂停、重置
- 时间到了会发送浏览器通知

#### 💬 和宠物对话
- 小型聊天对话框，显示在宠物下方
- 可以问宠物：
  - 我专注了多久？
  - 我现在在什么网站？
  - 询问休息建议
  - 随意聊天
- 宠物会智能回复

#### 👻 收起宠物
- 点击后隐藏桌宠
- 状态会保存，下次访问页面不会自动显示
- 可以从扩展 popup 重新显示

### 3. 🎨 视觉效果
- 赛博朋克风格的 UI
- 霓虹色彩（青色、粉色）
- 像素艺术风格
- 平滑的动画和过渡效果

## 使用方法

### 显示桌宠
1. 打开扩展 popup
2. 进入 Home 页面
3. 选择你想要的宠物
4. 点击 "Meet with [宠物名字] right now!" 按钮
5. 桌宠会立即出现在当前网页上

或者：
1. 在 Instruction 页面
2. 点击 "Meet with your buddy now!" 按钮

### 移动桌宠
- 直接拖动桌宠到任意位置
- 位置会自动保存

### 使用功能
1. **点击桌宠** → 弹出菜单
2. 选择想要的功能：
   - 专注计时器
   - 聊天对话
   - 收起宠物

### 收起/显示桌宠
- 在菜单中点击 "收起宠物" 隐藏
- 要重新显示，回到 Home 页面点击 "Meet with buddy" 按钮

## 技术实现

### 文件结构
```
extension/
├── entrypoints/
│   ├── content.tsx                    # Content script 入口
│   └── content/
│       ├── PetWidget.tsx              # 主桌宠组件
│       ├── FocusTimer.tsx             # 专注计时器
│       └── ChatBox.tsx                # 聊天对话框
├── pages/
│   ├── Home.tsx                       # 主页（已更新）
│   └── Instruction.tsx                # 说明页（已更新）
└── lib/
    └── utils/
        └── petControl.ts              # 桌宠控制工具函数
```

### 关键功能
1. **消息传递**：Popup ↔ Content Script 通信
2. **状态持久化**：使用 Chrome Storage API 保存位置和可见性
3. **GIF 支持**：直接使用 `<img>` 标签，浏览器原生支持
4. **拖动功能**：监听 mousedown、mousemove、mouseup 事件
5. **Shadow DOM**：使用 WXT 的 createShadowRootUi 隔离样式

## 注意事项

1. 桌宠会注入到**所有网页**（除了 Chrome 官方页面）
2. 第一次点击按钮后，需要刷新当前标签页才能看到桌宠
3. 计时器通知需要用户授予通知权限
4. GIF 文件会持续播放，注意文件大小以免影响性能
